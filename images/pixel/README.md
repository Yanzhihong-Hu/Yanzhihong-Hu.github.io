# Pixel campus artwork

Created for Yanzhihong Hu's existing Jekyll website on 2026-09-26 with the built-in imagegen tool. No framework, routes, biography data, or deployment workflow were replaced.

## Current assets (screenshot-led revision)

- `atlanta-campus-rpg.webp`: 1448 × 1086. Newly generated pixel neighborhood, with Tech Tower, an Atlanta skyline, outlined trees and tiled paths. Rendered at its full aspect ratio on mobile, without landmark cropping.
- `yanzhihong-rpg-portrait.webp`: 1254 × 1254. More simplified, coarser pixel portrait drawn from the same original photograph; head and neck only.
- `campus-tiles.svg`: original sparse paving seams and small grass clusters, used as a low-contrast background mask. No texture is drawn over text.
- Observed in the owner's three supplied screenshots: overhead RPG town views, outlined tree canopies, muted green/blue/cream colors, gray tiled paths and dark information boxes with stepped pale borders.
- Design choices for this site: a coherent imagined Georgia Tech / Atlanta neighborhood, separate readable biography panel, sage portrait background and sparse page texture. The scene mixes a raised town-map view with skyline depth; it is not a copy of the reference map or a geographic reconstruction.
- Artwork is generated raster illustration, not a CSS filter. Encoding to WebP does not alter the composition. Requested logical grid and color counts below describe the art direction, not measured output counts.
